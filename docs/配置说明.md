# 知域 KnowledgeScope — 配置说明

> 所有可调阈值、超时、长度与模型相关项集中于此。  
> **业务代码禁止出现含义不明的魔法数字/字符串**；实现时落入 `backend` 配置类（或常量类），与本表名称对齐。  
> 环境变量名建议：配置字段的 **SCREAMING_SNAKE_CASE**（与现有 `Settings` 一致）。

默认值可在落地时微调，但必须改配置、不得改散落字面量。

## 6. 问答与会话（Phase 2b）

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ANSWER_MODE_DEFAULT` | string | `strict` | 初期仅支持严格边界 |
| `CHAT_HISTORY_MESSAGE_LIMIT` | int | `10` | 交给聊天模型的最近消息条数 |
| `CHAT_MAX_OUTPUT_TOKENS` | int | `2048` | 生成上限（若 API 支持） |
| `CITATION_MAX_COUNT` | int | `8` | 单条助手消息最多附带引用数 |
| `CONVERSATION_TITLE_MAX_LENGTH` | int | `100` | 会话标题最长 |
| `CONVERSATION_TITLE_FROM_QUESTION_PREFIX` | int | `30` | 未命名会话时取首问前缀 |

严格边界无命中时的固定回复文案（常量，非环境变量亦可，但须集中定义）：

| 常量名 | 建议文案 |
|--------|----------|
| `STRICT_NO_EVIDENCE_REPLY` | `当前知识空间中未找到相关依据。` |

## 7. 系统默认模型（Phase 2b，环境变量 / `.env`）

用户未配置或未选择个人档时，回落到系统默认。前端列表须标注 **「默认」**。

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `DEFAULT_CHAT_BASE_URL` | string | （空则未配置） | OpenAI 兼容聊天 API Base URL |
| `DEFAULT_CHAT_API_KEY` | string | （空） | 聊天 Key；勿提交到 Git |
| `DEFAULT_CHAT_MODEL` | string | （空） | 聊天模型名 |
| `DEFAULT_EMBEDDING_BASE_URL` | string | （空，可与聊天相同） | 嵌入 API Base URL |
| `DEFAULT_EMBEDDING_API_KEY` | string | （空） | 嵌入 Key |
| `DEFAULT_EMBEDDING_MODEL` | string | （空） | 嵌入模型名 |
| `MODEL_API_KEY_MASK_VISIBLE_SUFFIX` | int | `4` | 脱敏时末尾可见字符数 |
| `MODEL_PROFILE_NAME_MAX_LENGTH` | int | `100` | 用户配置档名称最长 |
| `MODEL_BASE_URL_MAX_LENGTH` | int | `500` | Base URL 最长 |

`ModelProfile.purpose`：`chat` | `embedding`（枚举，非自由字符串散落）。

## 9. 维护约定

1. 新增阈值前：先改本文件与后端 `Settings`/常量类，再写业务代码。  
2. `.env.example` 同步列出键名（值可为空或示例）。  
3. 前端展示的「默认模型」来自服务端接口标记（如 `isSystemDefault: true`），不要前端写死模型名。
